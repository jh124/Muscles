# Muscles

A manual workout tracker and companion to [Daily](https://jh124.github.io/Daily/).

Muscles is a lightweight installable web app with no build dependencies. Workout history is stored locally on your device. Export a JSON backup regularly to keep your data safe.

## Publishing

On GitHub, open **Settings → Pages**, set **Deploy from a branch**, select **main** and **/(root)**, then Save. Open `https://jh124.github.io/Muscles/` once GitHub Pages is active. In Safari, use **Share → Add to Home Screen** to install it.

## Privacy

Muscles doesn't send workouts to a server, and it doesn't automatically synchronize data with Daily. JSON import/export lets you back up or transfer records between devices.
